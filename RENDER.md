# Render deployment

Recommended: Render **Web Service**

Build command:
`npm install && npm run build`

Start command:
`npm start`

Node version: 20 or newer.

If you prefer Render Static Site, first export the app with a Next.js static-output configuration and adapt the dynamic routes accordingly. The supplied project is configured as a normal Next.js app because it leaves room for a CMS/API-backed assessment form later.

## Before production

1. Replace placeholder photos with Greenway's approved repository photos.
2. Confirm production email and phone.
3. Connect the field-assessment form to an approved inbox/CRM/form provider.
4. Confirm service area and approved leadership bios.
5. Add approved resource cover/download for Built Beneath the Surface.
6. Add legal/privacy/accessibility content supplied by Greenway.
